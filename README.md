📘 電商系統使用手冊

（Java + MySQL + Swing MVC 專案）

一、系統簡介

本系統為一套以 Java（Swing） 搭配 MySQL 所開發的簡易電商系統，
主要提供 消費者購物功能 與 管理者訂單管理功能。

系統採用：

Maven Project

MVC 架構

DAO Pattern

MySQL 資料庫

Eclipse + WindowBuilder 開發

二、系統角色說明
1️⃣ 消費者（User）

可註冊帳號

可登入系統

可瀏覽商品、加入購物車、結帳

可查看歷史訂單

2️⃣ 管理者（Admin）

透過管理者登入模式進入

可查詢所有訂單

可依條件（客戶 / 產品 / 金額區間）查詢訂單

以列表方式檢視訂單明細與金額

三、系統啟動方式

開啟 Eclipse

啟動 MySQL 並確認資料庫連線正常

執行 LoginUI

進入系統首頁

四、登入畫面（LoginUI）
🔹 功能說明

輸入帳號、密碼

提供兩種登入模式：

消費者登入

管理者登入模式


五、消費者功能操作流程
1️⃣ 消費者註冊

點擊「註冊」

輸入：

姓名

帳號

密碼

城市

地址

電話

若帳號重複，系統會提示錯誤

註冊成功後回到登入畫面

2️⃣ 消費者登入

輸入正確帳號與密碼

登入成功後進入「登入成功畫面」

3️⃣ 商品選購頁面（OrderListUI）

顯示所有商品與單價

使用者可輸入各商品購買數量

商品可單選或複選

支援：

滿 1000 元 → 9 折

滿 500 元 → 免運

未滿 500 → 運費 60 元

4️⃣ 購物車頁面（OrderCartUI）

顯示本次選購商品明細

顯示：

商品名稱

單價

數量

小計

折扣

運費

總金額

功能：

「確定結帳」→ 建立訂單並寫入資料庫

「返回商品列表」

5️⃣ 訂單確認 / 歷史訂單（OrderConfirmUI）

結帳後顯示剛剛完成的訂單

點擊「歷史訂單」可查看該帳號過去所有訂單

顯示內容包含：

訂單編號

訂單時間

商品明細

折扣、運費、總金額

六、管理者功能操作流程（AdminUI）
🔹 管理者登入

在 LoginUI 輸入管理者帳號與密碼

點擊「登入管理者模式」

驗證成功後進入管理者畫面

🔹 管理者畫面功能（列表呈現）

管理者畫面採用 JTable 表格方式呈現資料（類似資料庫查詢結果）

顯示欄位包含：

訂單編號

客戶編號

產品編號

產品名稱

單價

數量

小計

訂單時間

1️⃣ 查詢所有訂單

點擊「所有訂單」

顯示目前系統內所有訂單明細

2️⃣ 依客戶編號查詢

輸入客戶編號（如：U016）

點擊「查詢」

顯示該客戶所有訂單資料

3️⃣ 依產品編號查詢

輸入產品編號（如：P001）

點擊「查詢」

顯示購買該產品的所有訂單紀錄

4️⃣ 金額區間查詢

輸入最小金額與最大金額

點擊「查詢」

顯示小計落在該區間的訂單明細

5️⃣ 查詢總金額顯示

每次查詢後

系統會自動計算並顯示：
👉「本次查詢結果的總金額」

6️⃣ 清空查詢條件

點擊「清空」

清除：

所有輸入欄位

表格內容

查詢總金額

七、資料處理設計說明
🔹 資料庫設計

users

products

orders

order_items

v_order_detail（View）

🔹 金額計算原則

不在 SQL 存折扣/運費

所有金額計算皆於 Java 端完成

確保顯示與購物邏輯一致

八、系統特色與優點

MVC 架構清楚

DAO Pattern 易於維護

Swing UI 直覺操作

管理者訂單查詢彈性高

支援歷史訂單與條件查詢

程式邏輯與資料庫分離

九、注意事項

管理者帳密目前為固定寫死（作業用途）

系統未處理並發與交易鎖定（非本作業範圍）

建議在本機測試環境執行

十、結語

本系統完整實作了：

消費者購物流程

訂單資料寫入與查詢

管理者後台訂單管理

符合 Java MVC + DAO Pattern 的課程要求，
並具備實際電商系統的基本功能。
